# Análise de vendas de uma lanchonete

Projeto em desenvolvimento para aprender Python e análise de dados,
com um dashboard construído em Streamlit.

## Funcionalidades

- Faturamento total.
- Quantidade de pedidos.
- Ticket médio.
- Unidades vendidas.
- Análise de quantidade e faturamento por produto.

## Organização

- dados.py: pedidos de exemplo.
- analises.py: funções de cálculo.
- main.py: apresentação dos resultados no terminal.
- app.py: dashboard em Streamlit.

## Tecnologias

Python e Streamlit.
